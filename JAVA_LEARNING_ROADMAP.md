# Java Learning Roadmap

Этот файл — навигационная точка для учебной программы JavaPlay. Детальные уроки разложены по отдельным файлам в [docs/lessons](/Users/mku/Documents/ChatGPT/JavaPlay/docs/lessons).

## Назначение

Программа описывает путь от полного новичка до самостоятельного Java-разработчика. Она нужна не как учебник для игрока, а как источник проектирования игровых уровней, квестов, объяснений, практики и проверок.

Каждая тема должна превращаться в игровой цикл:

1. проблема в мире;
2. короткое объяснение;
3. пример Java;
4. малая практика;
5. самостоятельная задача;
6. наблюдаемый эффект в мире;
7. проверка навыка;
8. повторение в новом контексте.

## Правила развития

- Один урок вводит одну главную идею.
- Новая тема не требует знаний, которых ещё нет в prerequisites.
- Сначала игрок видит проблему мира, затем получает инструмент Java.
- Симулятор MVP явно называется ограниченным симулятором, а не JVM.
- Авторское решение и правила проверки позже хранятся отдельно от клиентского контента.
- Статус "принято" появляется только после ручной приёмки пользователем.
