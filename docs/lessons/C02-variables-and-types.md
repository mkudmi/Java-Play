# C02. Долина Переменных — Variables & Types

## Роль региона

Игрок учится сохранять значения под именами, выбирать простые типы и выполнять вычисления. Переменная вводится как подписанная ячейка, но с уточнением: для объектов переменная хранит ссылку, а не сам объект.

## Prerequisites

C01: готовый `main`, вывод, строковые литералы, базовое понимание выполнения программы.

## Обязательные понятия

- объявление;
- инициализация;
- присваивание;
- имя переменной;
- тип;
- литерал;
- арифметические операторы;
- приоритет операций и скобки;
- базовые примитивы;
- `String` как ссылочный тип, не примитив;
- переполнение и целочисленное деление.

## Границы

Не вводить `BigDecimal` как обязательный ранний инструмент, но не закреплять `double` для денежных расчётов. Не требовать пользовательского ввода из консоли: в игре значения задаются starter code и учебным API.

## Игровые квесты

- Задать запас энергии маяка.
- Рассчитать остаток топлива после короткого маршрута.
- Исправить неверный тип переменной на табло.
- Обнаружить переполнение счётчика как сюжетную поломку старого механизма.

## Проверяемые навыки

Игрок создаёт переменные с понятными именами, выбирает базовый тип под задачу, читает простые выражения и может предсказать результат арифметики до запуска.
