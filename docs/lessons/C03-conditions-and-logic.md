# C03. Перекрёсток Решений — Conditions & Logic

## Роль региона

Игрок учится заставлять программу выбирать разные действия в зависимости от условий. Мир впервые реагирует не только на значение, но и на решение.

## Prerequisites

C02: переменные, `boolean`, сравнения как идея числового отношения, базовая арифметика.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C03-L01 | Сравнения | `>`, `<`, `>=`, `<=`, `==`, `!=` | Проверить достаточный заряд | Табло показывает готовность |
| C03-L02 | `if` | Выполнить код при условии | Открыть ворота при пропуске | Ворота открываются только в одном сценарии |
| C03-L03 | `else` | Альтернативное действие | Показать отказ без пропуска | NPC получает понятную причину |
| C03-L04 | `else if` | Несколько веток | Выбрать режим маяка по энергии | Свет меняет интенсивность |
| C03-L05 | Boolean-логика | `&&`, `||`, `!` | Проверить пропуск и заряд | Диспетчер принимает сложное решение |
| C03-L06 | Короткое замыкание | Правая часть может не выполняться | Защитить обращение к опасному датчику | Механизм не падает при пустом датчике |
| C03-L07 | `switch` | Выбор по категории | Направить посылку по типу | Конвейер ведёт груз в нужную дверь |

## Обязательные понятия

- условное выполнение;
- блок кода;
- операторы сравнения;
- логические операторы;
- порядок проверки веток;
- короткое замыкание;
- `switch` для ограниченного набора вариантов.

## Границы

Не вводить коллекции, enum как самостоятельную модель и pattern matching. Ранний `switch` можно показать на строках или числах без углубления в новые возможности языка.

## Игровые квесты

- Диспетчер ворот проверяет пропуск.
- Маяк выбирает один из трёх режимов.
- Конвейер отправляет посылки по категориям и обрабатывает неизвестную категорию.

## Проверяемые навыки

Игрок пишет условия без дублирования лишних действий, понимает разницу между `=` и `==`, умеет объяснить, почему порядок веток влияет на результат.
