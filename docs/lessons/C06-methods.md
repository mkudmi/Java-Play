# C06. Город Методов — Methods

## Роль региона

Игрок учится отделять части алгоритма в именованные методы. Метод вводится как устройство с входами и результатом, но с уточнением: метод может иметь побочные эффекты.

## Prerequisites

C05: условия, циклы, массивы, базовые типы.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C06-L01 | Зачем метод | Именованная часть решения | Вынести расчёт энергии | Код терминала становится короче |
| C06-L02 | Параметры | Входные данные метода | Передать расстояние маршрута | Паром считает разные маршруты |
| C06-L03 | `return` | Результат метода | Вернуть стоимость запуска | Табло получает число |
| C06-L04 | `void` | Действие без результата | Напечатать отчёт | Журнал обновляется |
| C06-L05 | Область видимости | Переменная живёт в своём блоке | Исправить недоступное имя | Ошибка диагностики исчезает |
| C06-L06 | Перегрузка | Одно имя, разные параметры | Настроить запуск по числу или тексту | Механизм принимает два сценария |
| C06-L07 | Декомпозиция | Разделение задачи | Собрать запуск двигателя из шагов | Большой механизм запускается по порядку |

## Обязательные понятия

- сигнатура метода;
- параметр и аргумент;
- тип возвращаемого значения;
- `return`;
- `void`;
- локальная переменная;
- область видимости;
- перегрузка;
- простая декомпозиция.

## Границы

Не требовать проектирования классов и объектов. Методы можно писать внутри готового `Main`, чтобы не смешивать тему с ООП.

## Игровые квесты

- Вынести повторяющийся расчёт в метод.
- Исправить ошибку области видимости в табло.
- Босс: собрать запуск двигателя из методов `prepare`, `validate`, `start`.

## Проверяемые навыки

Игрок может назвать метод по действию, передать параметры, вернуть результат и объяснить, почему метод должен делать одну понятную часть задачи.
