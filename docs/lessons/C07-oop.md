# C07. Королевство Объектов — Object-Oriented Programming

## Роль региона

Игрок переходит от отдельных функций к моделированию предметной области. Класс — чертёж, объект — конкретный экземпляр; позже модель уточняется ссылками, памятью и жизненным циклом.

## Prerequisites

C06: методы, параметры, область видимости, массивы и условия.

## Обязательные понятия

Класс, объект, поле, метод, конструктор, `this`, `private`, getter/setter с осторожностью, `static`, `final`, наследование, overriding, полиморфизм, интерфейс, абстрактный класс, enum, record, композиция, `equals` и `hashCode`.

## Границы

Не превращать ООП в копирование UML. Каждая тема должна решать конкретную игровую проблему. Наследование показывать умеренно и сравнивать с композицией.

## Игровые квесты

- Убрать копипасту товаров в магазине через класс и объекты.
- Подключить разные механизмы через общий интерфейс.
- Спроектировать инвентарь с корректным равенством предметов.

## Проверяемые навыки

Игрок может объяснить ответственность класса, создать несколько объектов, спрятать состояние и заменить ветвление по типу полиморфизмом там, где это действительно упрощает задачу.
