# C08. Мастерская Строк — Strings

## Роль региона

Игрок учится работать с текстом как с важной частью реальных программ: командами, логами, именами, файлами и сообщениями.

## Prerequisites

C07. Базовое знакомство со `String` появляется в C02, но глубокая обработка текста требует методов и объектов.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C08-L01 | Неизменяемость `String` | Метод создаёт новую строку | Исправить забытое присваивание | Журнал очищается |
| C08-L02 | Сравнение строк | `equals`, не `==` | Починить командный терминал | Команды начинают распознаваться |
| C08-L03 | Полезные методы | `trim`, `toLowerCase`, `contains`, `substring` | Нормализовать ввод | NPC понимает разные записи |
| C08-L04 | Конкатенация | Сборка сообщения | Сформировать отчёт | Табло показывает понятный текст |
| C08-L05 | `StringBuilder` | Эффективная сборка текста | Собрать длинный журнал | Архив не тормозит на повторениях |
| C08-L06 | Regex | Шаблон текста | Найти повреждённые записи | Логи подсвечивают проблемы |
| C08-L07 | `StringBuffer` в контексте | Старый синхронизированный класс | Узнать в legacy-коде | Рэй объясняет исторический слой |

## Обязательные понятия

Неизменяемость, `equals`, регистр, пробелы, подстроки, конкатенация, форматирование на базовом уровне, `StringBuilder`, регулярные выражения, границы применения `StringBuffer`.

## Границы

Не называть `String` примитивом. Regex вводить как инструмент для простых шаблонов, а не как замену парсеру сложного языка.

## Игровые квесты

- Очистить журнал сообщений от лишних пробелов.
- Исправить сравнение команд.
- Найти записи с неверным кодом маяка по простому регулярному выражению.

## Проверяемые навыки

Игрок выбирает `equals` для сравнения содержимого, помнит про неизменяемость и может обработать текст без хрупкого набора случайных замен.
