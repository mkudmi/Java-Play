# C12. Архив Файлов — Files & IO

## Роль региона

Игрок связывает программу с данными вне памяти: файлами, путями, кодировками и ресурсами.

## Prerequisites

C08, C09, C10: строки, исключения, коллекции.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C12-L01 | `Path` | Путь к файлу | Собрать путь к журналу | Архив находит запись |
| C12-L02 | `Files.readString` | Прочитать текст | Открыть повреждённый журнал | Текст появляется в терминале |
| C12-L03 | Кодировки | Байты и текст | Исправить неверное чтение | Символы становятся читаемыми |
| C12-L04 | Запись файла | Сохранить данные | Создать отчёт | Архив получает новый документ |
| C12-L05 | Потоки IO | Последовательное чтение данных | Прочитать большой журнал | UI не требует хранить всё сразу |
| C12-L06 | Ресурсы | Закрытие обязательно | Использовать try-with-resources | Замки архива освобождаются |
| C12-L07 | Сериализация и ограничения | Не доверять бинарной магии | Обсудить безопасные форматы | Архив выбирает JSON/текст для учебных данных |

## Обязательные понятия

Файл, директория, путь, относительный и абсолютный путь, кодировка, чтение, запись, stream, buffer, resource, try-with-resources, ограничение нативной Java-сериализации.

## Границы

Не запускать работу с произвольными файлами пользователя в игре без sandbox и разрешений. Не рекомендовать нативную десериализацию недоверенных данных.

## Игровые квесты

- Восстановить архив логов.
- Прочитать список задач и пропустить повреждённые строки.
- Записать отчёт о восстановлении региона.

## Проверяемые навыки

Игрок читает и пишет текстовые данные, обрабатывает ошибки ввода-вывода и закрывает ресурсы без утечки.
