# C13. Река Потоков — Functional Java

## Роль региона

Игрок учится описывать преобразования данных компактно и безопасно, не теряя понимания происходящего.

## Prerequisites

C08, C10, C11: строки, коллекции, generics.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C13-L01 | Functional interface | Поведение как значение | Передать правило фильтра | Сортировщик меняет режим |
| C13-L02 | Lambda | Короткая функция | Отфильтровать заказы | Река пропускает нужные грузы |
| C13-L03 | Method reference | Ссылка на существующий метод | Упростить преобразование | Код терминала становится яснее |
| C13-L04 | Stream pipeline | Поток операций над коллекцией | `filter` + `map` | Конвейер показывает этапы |
| C13-L05 | `reduce` | Свернуть в итог | Посчитать общий вес | Весы показывают сумму |
| C13-L06 | Collectors | Собрать результат | Сгруппировать заказы | Совет видит сводку по районам |
| C13-L07 | `flatMap` | Развернуть вложенные данные | Собрать товары из заказов | Склад видит общий список |
| C13-L08 | Optional | Явное отсутствие значения | Найти товар без `null` | Терминал не падает при пустом результате |
| C13-L09 | Ленивость и побочные эффекты | Stream выполняется при terminal operation | Найти пропущенный запуск | Рэй показывает трассировку |

## Обязательные понятия

Functional interface, lambda, method reference, intermediate/terminal operation, laziness, side effects, `map`, `filter`, `reduce`, `collect`, `groupingBy`, `Optional`.

## Границы

Не использовать Stream API до коллекций. Не делать stream обязательным там, где обычный цикл яснее для ученика.

## Игровые квесты

- Посчитать торговую сводку по районам.
- Найти дорогие заказы и вывести названия.
- Безопасно обработать отсутствующий товар через `Optional`.

## Проверяемые навыки

Игрок понимает поток данных по шагам, может переписать простой цикл в stream и обратно, а также избегает скрытых побочных эффектов в pipeline.
