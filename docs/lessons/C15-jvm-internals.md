# C15. Подземелья JVM — JVM Internals

## Роль региона

Игрок связывает высокоуровневый Java-код с платформой выполнения: памятью, сборкой мусора, загрузкой классов и производительностью.

## Prerequisites

C12, C14: файлы, ресурсы, конкурентность. Простые модели памяти вводились раньше, но глубокая тема начинается здесь.

## Обязательные понятия

Stack frame, heap object, reference, reachability, garbage collection, class loader, bytecode, JIT, profiling, allocation, retained objects, memory leak.

## Границы

Не требовать знания конкретного GC-алгоритма до базового понимания достижимости. Не обещать точные performance-выводы без измерений.

## Игровые квесты

- Найти удерживаемые объекты в мастерской.
- Объяснить, почему две ссылки меняют один объект.
- Прочитать простой фрагмент байткода как иллюстрацию, не как основной язык.

## Проверяемые навыки

Игрок понимает, почему память не равна переменным в коде, умеет описать достижимость объекта и знает, что оптимизация начинается с профилирования.
