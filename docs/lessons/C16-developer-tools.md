# C16. Порт Инструментов — Developer Tools

## Роль региона

Игрок выходит из изолированного игрового редактора к реальным инструментам разработчика: IDE, Git, сборке, зависимостям, логированию и отладке.

## Prerequisites

Раннее знакомство возможно после C06. Полная ветка требует C09, чтобы понимать ошибки и диагностику.

## Обязательные понятия

JDK, IDE, project structure, debugger, breakpoint, step over/into, Git working tree, commit, branch, merge conflict, dependency, Maven lifecycle, Gradle task, logging level.

## Границы

Не делать инструменты главным препятствием до базовой Java. Не требовать идеального Git flow от новичка; сначала история и восстановимость.

## Игровые квесты

- Экспортировать маленький проект из игры.
- Найти баг через debugger.
- Собрать проект с зависимостью и зафиксировать изменение в Git.

## Проверяемые навыки

Игрок может запустить Java вне игры, прочитать структуру проекта, сделать осмысленный commit и использовать debugger для поиска причины ошибки.
