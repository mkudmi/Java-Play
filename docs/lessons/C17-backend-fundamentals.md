# C17. Сеть Городов — Backend Fundamentals

## Роль региона

Игрок узнаёт, как программы общаются по сети, что такое API и почему договор между клиентом и сервером важен.

## Prerequisites

C12, C13, C16: данные, обработка коллекций, инструменты разработчика.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C17-L01 | Client/server | Разделение ролей | Нарисовать путь запроса | Почтовые станции соединяются |
| C17-L02 | HTTP request | Method, URL, headers, body | Отправить GET | Станция возвращает статус |
| C17-L03 | HTTP response | Status code и body | Обработать 200/404/500 | Мир показывает разные исходы |
| C17-L04 | JSON | Текстовый формат данных | Разобрать заказ | Склад понимает сообщение |
| C17-L05 | REST | Ресурс и действие | Спроектировать endpoint | Карта получает единый договор |
| C17-L06 | Idempotency | Повтор не должен вредить | Повторить оплату безопасно | Двойная покупка не происходит |
| C17-L07 | Basic client | Вызов внешнего API в учебной среде | Получить список станций | Города появляются на карте |

## Обязательные понятия

Клиент, сервер, request, response, method, URL, status code, header, body, JSON, REST resource, API contract, идемпотентность, timeout на уровне идеи.

## Границы

Не вводить Spring до C19. Не открывать произвольную сеть для задач с недоверенным кодом без отдельного профиля sandbox.

## Игровые квесты

- Соединить почтовые станции через учебный API.
- Обработать разные HTTP-статусы.
- Спроектировать контракт заказа.

## Проверяемые навыки

Игрок может объяснить, что именно отправляет клиент, что отвечает сервер и почему повтор запроса должен быть продуман.
