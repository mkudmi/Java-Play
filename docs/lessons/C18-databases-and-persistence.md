# C18. Хранилище Города — Databases & Persistence

## Роль региона

Игрок учится хранить данные устойчиво и согласованно: сначала SQL и реляционная модель, затем JDBC, JPA и Hibernate.

## Prerequisites

C09, C10, C16, C17: исключения, коллекции, инструменты, HTTP/API.

## Последовательность уроков

| ID | Урок | Новая идея | Практика | Эффект мира |
|---|---|---|---|---|
| C18-L01 | Таблица | Строки и столбцы | Описать товары | Склад получает реестр |
| C18-L02 | Primary key | Уникальная идентичность | Найти заказ по ID | Дубликаты исчезают |

## Обязательные понятия

Реляционная таблица, schema, primary key, foreign key, SQL, CRUD, join, index, transaction, isolation на базовом уровне, JDBC, prepared statement, entity, repository, ORM, lazy loading как будущий риск.

## Границы

Не объяснять Hibernate раньше SQL и JDBC. Не учить строить SQL конкатенацией пользовательского ввода.

## Игровые квесты

- Восстановить складскую БД.
- Найти заказ через JOIN.
- Исправить оплату, которая списывает деньги без выдачи товара.

## Проверяемые навыки

Игрок может написать базовый SQL-запрос, объяснить ключи и транзакцию, а также понимает, что ORM не отменяет модель базы данных.
