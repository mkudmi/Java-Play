# C19. Столица Сервисов — Spring Ecosystem

## Роль региона

Игрок собирает настоящий backend на Spring Boot, применяя Java Core, ООП, HTTP, SQL и инструменты сборки.

## Prerequisites

C07-C13, C16-C18. Spring закрыт до уверенного понимания Java Core, ООП, HTTP и баз данных.

## Обязательные понятия

Spring Boot, application context, bean, dependency injection, controller, service, repository, DTO, validation, exception handler, configuration properties, logging, transaction boundary.

## Границы

Не объяснять Spring как "магия всё сделает". Каждый механизм должен связываться с уже известной Java-идеей: интерфейс, объект, исключение, HTTP, транзакция.

## Игровые квесты

- Создать API витрины.
- Перенести бизнес-логику из controller в service.
- Исправить транзакционный дефект покупки.

## Проверяемые навыки

Игрок строит простой слойный сервис, понимает роль DI и может объяснить, где должны жить HTTP, бизнес-правила и доступ к данным.
