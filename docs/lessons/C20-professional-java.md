# C20. Инженерная Гильдия — Professional Java Developer

## Роль региона

Финальный регион проверяет перенос навыков в большие задачи: проектирование, качество, тестирование как учебная тема, безопасность, Docker, performance, legacy code и самостоятельное развитие.

## Prerequisites

C14, C15, C19 и завершённая база Java Core, инструментов, HTTP и данных.

## Обязательные понятия

Clean Code, SOLID, patterns как язык обсуждения, code review, refactoring, JUnit, Mockito, integration tests, Testcontainers, Docker, auth/authz, input validation, logging, metrics, profiling, documentation, legacy code.

## Границы

Юнит-тесты репозитория JavaPlay сейчас не создаются. Тестирование здесь описано как будущая учебная тема для игрока и не отменяет текущие ограничения проекта.

## Игровые квесты

- Провести code review дефектного сервиса.
- Защитить заказ от доступа чужого пользователя.
- Собрать финальную систему: магазин, склад, транспорт, API, БД, документация и сценарии восстановления.

## Проверяемые навыки

Игрок способен получить задачу без готовой формулы, разбить её на компоненты, реализовать, объяснить решения, проверить поведение и наметить дальнейшее развитие.
