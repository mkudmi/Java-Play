# Индекс отдельных уроков JavaPlay

Папка содержит проектные файлы уроков для будущих уровней. Это не runtime-контент игры и не готовые тексты всех диалогов, а методическая база для level design.

## Как пользоваться

Каждый файл `Cxx` описывает один регион курса и набор малых уроков внутри него. При проектировании конкретного квеста автор берёт одну учебную единицу, раскрывает её по [шаблону](/Users/mku/Documents/ChatGPT/JavaPlay/docs/lessons/LESSON_TEMPLATE.md), добавляет starter code, проверку, подсказки и визуальный результат.
