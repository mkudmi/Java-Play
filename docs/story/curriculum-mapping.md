## Checkpoint Integration

Каждый checkpoint — сюжетное испытание, где игрок применяет несколько уже изученных тем без прямой подсказки конструкции. Ранние checkpoint могут говорить "используй if"; после C07 формулировка смещается к требованию мира: "товар не должен выдаваться дважды", "ресурс должен закрыться", "сервис должен отвечать одинаково при повторе".
