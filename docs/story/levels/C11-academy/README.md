# CHAPTER 11 — Грузы без подмены

## Narrative Purpose

Показать generics как ответ на архитектурную проблему повторяющихся контейнеров и ошибок типов.

## Curriculum Coverage

C11. Академия Обобщений: generic classes/methods, bounds, wildcards, PECS, type erasure, raw types.

Related Curriculum IDs: JAVA-C11-L01, JAVA-C11-L02, JAVA-C11-L03, JAVA-C11-L04, JAVA-C11-L05, JAVA-C11-L06.

## Starting Situation

Академия Совместимости хранит десятки почти одинаковых контейнеров: для руды, еды, документов, деталей. Один raw-контейнер принимает опасный предмет как обычный груз.

## Central Problem

Нужно одно решение для разных типов, но с проверкой безопасности на этапе компиляции.

## Why Existing Knowledge Is Not Enough

Коллекции уже используют `List<Item>`, но игрок еще не умеет проектировать собственные типобезопасные компоненты.

## New Knowledge

`Box<T>`, generic methods, bounds, wildcards, `extends` для источника, `super` для приемника, erasure и ограничения runtime.

## Narrative Integration

Контейнеры принимают только допустимый груз, инспектор читает общий вес из разных подтипов, а перегрузка между складами требует PECS.

## Key Characters

Север, преподавательница Као, Бор.

## Main Quest Chain

1. Создать типизированный контейнер.
2. Написать generic method для первого элемента.
3. Ограничить типы только грузами.
4. Прочитать список разных подтипов.
5. Переложить грузы безопасно.
6. Разобрать, почему нельзя проверить `T` как обычный класс во время выполнения.

## Optional Side Stories

Бор просит "просто поставить Object", и Академия вежливо показывает симулятор последствий.

## Educational Escalation

От `Box<T>` к PECS и пониманию границ стирания типов.

## Chapter Mystery

Raw types встречаются в старых модулях Куратора, где безопасность типов была принесена в жертву совместимости.

## Story Reveal System

| What Player Believes | New Evidence | What Actually Happened | Remaining Questions |
|---|---|---|---|
| Ошибка в контейнере локальна. | Raw-код связан с централизованными адаптерами. | Куратор использовал небезопасные мосты между старыми типами. | Где хранятся исходные записи этих адаптеров? |

## Chapter Climax

Портовые контейнеры становятся совместимыми без потери типовой безопасности.

## Curriculum Checkpoint

Игрок объясняет `extends` для producer и `super` для consumer.

## Chapter Resolution

Академия отправляет героя в Нижний Архив искать историю адаптеров.
